This directory holds the PaySoft v2 build process visualization.

- `build-visualization-spec.md` — the complete data model and layout spec (read this first)
- `build-map.html` — (Phase 4+) the interactive visualization, generated from the spec

The visualization is a living map of every file, component, and resource in the application. Completed items are green, pending items are gray, external services are blue. Layer branches are toggleable to highlight their components.
